# Title background images

Original images generated for Mixtri using the built-in image generation tool, September 2026.
No third-party stock image is included. The selected dark image is Eclipse; the six light
images are Porcelain, Celadon, Mist Blue, Lilac, Clay, and Champagne.

These PNG files are shipped as Content and copied to Assets/TitleBackgrounds in the app.
Projects use stable `mixtri-title:` references rather than machine-specific installation paths.
The renderer resolves these references and applies broad, playhead-driven organic displacement
so the rendered surfaces flow in place, accompanied by subtle zoom, drift, and rotation.
The text is drawn afterward and is unaffected by background motion.
Keep existing filenames available for saved-project compatibility.

Art direction: original abstract 3D sculpture; broad folds, curved planes, frosted glass,
and dunes; quiet space for typography; gentle studio lighting and enough crop margin for drift.
Eclipse uses neutral charcoal. Light variants retain their sage, blue, lilac, clay, or sand
color in midtones and shadows. No lettering, logos, bright neon, or busy patterns.
